## 第1節・演習問題3.5：ニュートンの差商公式によるf(1)の計算

### 目的・言語

PDFでは、次の5点からニュートンの差商公式で補間多項式を作り、`x = 1.0` における値を求めている。掲載プログラムの言語はCである。

| x | 0.0 | 0.4 | 2.0 | 3.0 | 5.0 |
| --- | --- | --- | --- | --- | --- |
| f(x) | 1.0000 | 1.0315 | 3.0000 | 5.2915 | 11.225 |

### アルゴリズム・処理手順

1. `xt`、`yt` の5点を `x`、`y` に複写する。
2. 差商表の0列目に関数値を格納する。
3. 差商の再帰式を用いて、1～4次差商を順に計算する。
4. `xx = 1.0` とし、ニュートン補間多項式の各項を加算する。
5. `printf` で補間値を小数点以下4桁まで表示する。

理解のための説明として、差商表の構築は二重ループであり、点数をnとすると計算量はO(n²)、表の格納量もO(n²)である。多項式の評価では積を使い回すためO(n)となる。

### 重要な変数・関数

| 名前 | 役割 |
| --- | --- |
| `N` | 配列の上限。原本は11で、使用する点数は `n = 5` |
| `xt`、`yt` | PDFの数表を格納した初期値 |
| `x`、`y` | 補間点の座標と関数値 |
| `dd[i][j]` | i番目の点から始まるj次差商 |
| `i`、`j` | 差商表の位置・次数を走査する添字 |
| `xx` | 評価点。原本では1.0 |
| `prod` | `(xx-x[0])` から始まる因子の累積積 |
| `s`、`k` | 補間値の累積和と評価する項の添字 |
| `main`、`printf` | プログラムの入口と結果表示 |

### 数式とコードの対応

原本の式(2)の差商の定義は、次の対応となる。

```text
dd[i][0] = y[i]
dd[i][j] = (dd[i+1][j-1] - dd[i][j-1]) / (x[i+j] - x[i])
```

`dd[0][k]` がニュートン補間多項式のk次の係数である。`s = dd[0][0]` で定数項から始め、`prod *= (xx - x[k-1])` で積を伸ばし、`s += dd[0][k] * prod` で各項を加える。

```text
P(xx) = dd[0][0] + Σ(k=1..n-1) dd[0][k] × Π(m=0..k-1)(xx-x[m])
```

PDFには係数の丸め値 `1.0000, 0.078750, 0.575781, -0.055877, 0.003216` が掲載されている。コードはこれらを定数として使わず、差商表から計算する。

### 掲載された実行結果

PDF 3ページのコード末尾のコメントと本文は、次の結果を記載している。

```text
f(1.0) = 1.4616
```

PDFの手計算では `P(1) = 1.461605` と記載され、小数点以下4桁では上の表示と一致する。

### 注意点・原本照合

PDF 3ページの表示と、変数名、定数、演算子、ループ、書式文字列、日本語コメントを照合した。掲載上の行番号は除去した。原本19行目のセミコロンは次の表示行に折り返されているため、保存ファイルでもセミコロンの改行を維持している。このため保存ファイルは33行である。

判読できずに補完したコードはない。PDFでは元ファイルのタブと空白の区別や改行コードまでは確定できないため、字下げは表示に合わせた空白、改行はLFで保存した。

理解のための説明として、求める値は数表を通る4次補間多項式の値であり、元の関数を直接評価した値とは区別する。PDFの考察は元の関数を `sqrt(1+x^3)` とし、その `x = 1` における値 `sqrt(2)` と補間値との差を論じている。数表の値は掲載された桁数に丸められており、コードはその丸め済みデータをそのまま使用する。

## 第2節・プログラム3.2（newhkn.c）36～48行目の動作解説

### 目的・言語・保存範囲

言語はC。PDFはニュートンの差商公式を実装する `newhkn.c` のうち、入力した点における補間多項式の値を繰り返し表示する36～48行目を掲載している。[newhkn_lines_36_48.c](newhkn_lines_36_48.c) はこの13行だけの抜粋である。`#include`、変数宣言、`main`、点の入力、差商表の構築部分は掲載されておらず、補完していない。

### アルゴリズム・処理手順

1. `while( 1 )` で入力と評価を繰り返す。
2. `scanf("%lf%c",&x,&zz)` で評価点を読み込む。
3. `s = a[0][1]`、`t = 1` で和と積を初期化する。
4. `j = 2` から `n` まで、積に新しい因子を掛け、係数との積を和に加える。
5. 評価点と補間値を表示して、次の入力に戻る。

### 重要な変数・関数

| 名前 | PDFで説明された役割 |
| --- | --- |
| `a[i][0]` | 補間点のx座標 |
| `a[i][1]` | 関数値、すなわち0階差商 |
| `a[i][j]` | i番目の点から始まる(j−1)階差商 |
| `n`、`j` | 補間点数と加算する項の添字 |
| `x` | 入力された評価点 |
| `zz` | `%c` で入力末尾の改行を読み取るためのダミー変数 |
| `t`、`s` | 因子の累積積と補間値の累積和 |
| `scanf`、`printf` | 評価点の入力と結果表示 |

### 数式とコードの対応

PDFの式(10)は、次のニュートン補間多項式を表す。

```text
P(x) = a[0][1] + Σ(j=2..n) a[0][j] × Π(m=0..j-2)(x-a[m][0])
```

原本39～40行目で定数項と積を初期化する。43行目の `t *= (x - a[j-2][0])` が積に次の因子を加え、44行目の `s += a[0][j] * t` が対応する項を加算する。第1節の `dd` と異なり、`a` は0列目にx座標が入るため、差商の列番号が1つずれる。

### 掲載された実行結果

この抜粋に対する具体的な入力値・数値出力の実行例はPDFに掲載されていない。PDF 5ページには、反復ごとに `t` と `s` がどう更新されるかを示す記号によるトレースがある。

### コンパイル・実行方法と確認結果

抜粋には必要な宣言や外側の関数がないため、このファイル単独でのコンパイル・実行方法はない。プログラム全体のビルド方法も、このPDFだけからは確認できない。実行確認は行っていない。

### 注意点・原本照合

PDF 4ページの13行を表示と照合し、掲載上の行番号を除去して保存した。抽出テキストで `%10.6 lf` のように入った空白は、拡大表示に基づき `%10.6lf` と転記した。`printf` の日本語プロンプト、書式内の空白、原本コメントを維持した。

終了条件のない無限ループであり、PDF本文ではCtrl+Cによる終了が説明されている。理解のための説明として、`scanf` の戻り値を確認しない点やEOF時に終了しない点も掲載コードの挙動として残している。抜粋外のコードは未復元であり、プログラム3.2全体を復元済みとは扱わない。
