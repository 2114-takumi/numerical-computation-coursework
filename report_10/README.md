## コードの処理と補足説明

### 処理手順

1. `math` を読み込み、被積分関数 `f(x)` を定義する。
2. 積分区間を `a = -1.0`、`b = 2.0` とし、真値 `I_true` を計算する。
3. `trapezoidal(n)` と `simpson(n)` を定義する。
4. `n = 10` について近似値 `T`、`S` と、それぞれの絶対誤差を表示する。
5. 分割数を `[4, 8, 10, 20, 50, 100]` と変え、各手法の絶対誤差を表示する。

### 数式と実装の対応

どちらの関数も `h = (b - a) / n` により等間隔に分割する。`x_i = a + i h` とすると、台形公式は次の式になる。

$$
T_n = h\left[\frac{f(a)+f(b)}{2} + \sum_{i=1}^{n-1} f(x_i)\right]
$$

`s = 0.5 * (f(a) + f(b))` が端点の半分の重み、`s += f(a + i * h)` が内点の和に対応し、最後に `h * s` を返す。

シンプソン公式は、偶数の分割数に対して次の式で計算する。

$$
S_n = \frac{h}{3}\left[f(a)+f(b)
  +4\sum_{\substack{1\leq i<n\\i\text{ が奇数}}} f(x_i)
  +2\sum_{\substack{1\leq i<n\\i\text{ が偶数}}} f(x_i)\right]
$$

`4.0 if i % 2 == 1 else 2.0` により内点の重みを4、2、4、2…と切り替え、`h / 3.0 * s` を返す。両手法とも内点を1回ずつ調べるため計算量は `O(n)`、関数内で使う補助記憶量は `O(1)` である。

| 名前 | 役割 |

次の点はコードの理解のための注意であり、コードは変更していない。

- `simpson(n)` は偶数の正の分割数を前提とするが、引数がその条件を満たすかの検査はない。掲載コードが使う分割数はすべて正の偶数である。

- `I_true` は解析的な式を浮動小数点で評価した値であり、コードが表示する絶対誤差も、その値との差である。
- コードは近似値を小数点以下10桁、誤差を指数表記の小数点以下3桁で表示する。PDFの表はこれより少ない桁数に丸められている。
