## PDFに記載された目的・設定

次の波動方程式を差分法で解く課題である。使用言語はPythonで、配列計算にNumPy、図の作成にMatplotlibを使用する。

$$
\frac{\partial^2 z}{\partial t^2}
=2\frac{\partial^2 z}{\partial x^2},\qquad 0\leq x\leq4,\quad t\geq0
$$

初期変位は中央の高さが1の三角形であり、初期速度は0、両端の変位は常に0である。

$$
z(x,0)=\begin{cases}
0.5x & 0\leq x\leq2,\\
-0.5x+2 & 2\leq x\leq4,
\end{cases}
\qquad z_t(x,0)=0
$$

$$
z(0,t)=z(4,t)=0
$$

| 設定 | 値 |
| --- | --- |
| 方程式の係数 `c` | 2.0 |
| 空間区間の長さ `L` | 4.0 |
| 空間刻み幅 `h` | 0.5 |
| 空間分割数 `N` | 8 |
| 時間刻み幅 `k` | `h / sqrt(c)`、約0.353553 |
| 時間ステップ数 `M` | 16 |
| 計算する最大時刻 | `16k = 4sqrt(2)`、約5.656854 |

ここで原本の `c` は2階空間微分に掛かる係数であり、波の速さは `sqrt(c) = sqrt(2)` である。

## 差分式とコードの対応（補足説明）

`x_i = ih`、`t_j = jk` とし、時間・空間の2階微分を中心差分で近似すると、`r = k/h` を用いた一般の更新式は次のようになる。

$$
z_{i,j+1}=cr^2z_{i+1,j}+2(1-cr^2)z_{i,j}+cr^2z_{i-1,j}-z_{i,j-1}
$$

掲載コードは `k = h / np.sqrt(c)` とするため `cr² = 1` になり、次の簡略化した式を使う。

$$
z_{i,j+1}=z_{i+1,j}+z_{i-1,j}-z_{i,j-1}
$$

PDFは添字を空間、時間の順で書いているが、コードの配列 `z[j, i]` は**行が時間、列が空間**である。したがって更新式は次のスライス演算に対応する。

```python
z[j + 1, 1:N] = z[j, 2:N + 1] + z[j, 0:N - 1] - z[j - 1, 1:N]
```

`1:N` は端点を除いた空間位置、`2:N + 1` はその右隣、`0:N - 1` は左隣を表す。右辺の3つの配列を要素ごとに計算し、次の時刻の内点をまとめて更新する。

最初の更新には過去の時刻 `j = -1` がないため、初期速度0に対応する対称性 `z_{i,-1} = z_{i,1}` を用いて、次の式を使用している。

$$
z_{i,1}=\frac{z_{i+1,0}+z_{i-1,0}}{2}
$$

```python
z[1, 1:N] = 0.5 * (z[0, 2:N + 1] + z[0, 0:N - 1])
```

## 処理手順・重要な変数（補足説明）

1. NumPy、Matplotlibと3次元描画用のインポートを行い、フォントを原本どおり `MS Gothic` に設定する。
2. 定数と刻み幅を設定し、9個の空間格子点 `x` と、17行×9列の配列 `z` を作る。
3. `np.where` で初期変位を設定し、すべての時刻について両端の値を0に設定する。
4. 初期速度0から `j = 1` の行を求める。
5. `j = 1` から15まで順に、簡略化した差分式で次の時刻を求める。
6. 時刻の配列 `t` を作り、格子位置、各時刻、数値解の全行を表示する。
7. 偶数ステップの波形を重ねて描画し、`fig_wave.pdf` を保存する。
8. `np.meshgrid` で描画用の座標を作り、曲面を描画して `fig_3d.pdf` を保存する。

| 名前 | 役割 |
| --- | --- |
| `c`, `L`, `h`, `N`, `k`, `M` | 方程式の係数、領域長、空間刻み、空間分割数、時間刻み、時間ステップ数。 |
| `x` | `np.linspace` で作成する空間格子点。0.0～4.0の9点。 |

| `j` | 時間方向の添字。更新・表示・波形の選択に使う。 |

| `X`, `T`, `ax` | 曲面描画の格子座標と3次元のAxes。 |

数値解の更新には `O(MN)` の計算を行い、全時刻を保存する配列には `O(MN)` の記憶領域を使う。この説明は数値計算部分についての補足であり、描画に掛かる時間や領域は含めていない。
